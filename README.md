# Costa Sur

Juego de mundo abierto en vista cenital inspirado en el género de los GTA clásicos. Todo el código está en un único `index.html`, sin dependencias ni compilación.

## Cómo jugar

| Tecla | Acción |
|---|---|
| WASD / flechas | Caminar y conducir |
| Shift | Correr |
| Espacio | Freno de mano |
| E | Subir o bajar de un coche (robarlo) |
| Ratón + clic / F | Disparar a pie |

Recoge paquetes, entrégalos a tiempo y gana dinero. Atropellar o disparar a peatones y robar coches sube tu nivel de búsqueda: la policía te perseguirá y, con 3 estrellas o más, te disparará.

## Publicar en GitHub Pages

1. Crea un repositorio y sube `index.html` y este `README.md`.
2. Ve a **Settings → Pages**.
3. En *Source* elige la rama `main` y la carpeta `/ (root)`.
4. En un minuto estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
